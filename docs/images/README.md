# Interface screenshots

Captured from the native GTK4/libadwaita application on Fedora on September 17,
2026, at 1440 × 1040 with the light application appearance and a dark device theme.
These are screenshots of a demonstration layout, not design mock-ups. Preview
artwork uses the daemon renderer and cached live state. The capture window blocks
configuration writes and hardware actions; it does not replace the saved layout.

The Home, Pages, Keys, Dials, Plugins and About views are embedded or linked from the root
README using relative paths so the images travel with the repository to Gitea or
GitHub. When updating screenshots, use generic labels, check for personal data,
and inspect all captured images before publishing. Keep these files in the repo;
files under `local/` are not published.

## V1 video tour

`decksmith-v1-tour-thumbnail.png` and `decksmith-v1-tour.srt` accompany the
approved [V1 video tour](https://www.youtube.com/watch?v=ZJG1n_8rGNY), hosted on
James Senecal's YouTube channel. The 2-minute 58-second video shows native V1
interfaces in Fedora Workstation 44, Fedora Workstation 45 Beta and Ubuntu 26.04
test VMs with VirtualDeck and a sample layout/status. Fedora 44 remains the
supported V1 platform; these captures do not qualify physical hardware or live
meter performance. Debian and experimental plugins are not covered.

The final cut uses half-second fades, four-second stationary title cards and
five-second interface views. English captions and music credits accompany the
video, which discloses ChatGPT and Codex assistance. The earlier preview tour
assets remain available for historical reference.

## Dual-arc dial gauge examples — October 9, 2026

`decksmith-dial-gauges.png` and `decksmith-dial-gauges-muted.png` are lossless
800×100 touch-strip frames generated by the current Rust application renderer.
A private capture fixture supplies generic target labels, volume/signal values
and microphone mute states to VirtualDeck and the editor-preview renderer; their
RGB output is verified byte-for-byte equal. These are static demonstration
states, not recordings of live audio or separately drawn mock-ups. No physical
USB handle is opened, saved layout replaced or audio setting changed.

The first image shows independent blue setting arcs, outer signal arcs, green
microphone Live text and brightness. The second changes only microphone mute,
showing the red crossed-out icon and Muted text without a red border. These
examples describe development/COSMIC-preview artwork, not an update to the
original V1, Debian or Ubuntu release bytes. Older native editor screenshots
remain useful for layout and the available Classic bar presentation.

`decksmith-single-arc-meter.png` uses the same private capture method and synthetic
values with the current development renderer. Speakers retain Dual-arc, Browser
and Microphone use Single-arc meter, and Brightness retains its setting gauge.
The single activity arcs sit left of the configured volume percentage; microphone
Live/Muted uses the same right-hand readout as Dual-arc. The image verifies mixed
styles without changing assigned actions. Single-arc
is newer than the published COSMIC preview; the existing signed assets are unchanged.
