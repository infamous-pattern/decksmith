# Decksmith 1.5 — Stream Deck + and MK.2 together

**Published October 16, 2026.** [V1.5 downloads](https://github.com/infamous-pattern/decksmith/releases/tag/v1.5.0)
passed fresh public signature, hash and archive verification.

Decksmith 1.5 runs Stream Deck + and the standard 15-key Stream Deck MK.2 together
on Fedora Workstation 44. Each keeps its own saved layouts, pages and brightness.
Your existing Plus layout is preserved; a newly added MK.2 starts with its own
defaults.

## What changed

- Choose the device to edit while both Decks keep running. Save and restore its
  layout without changing the other device.
- Control shared audio and media from either Deck. Plus readouts and live meters
  follow their saved output, application, microphone or System sounds targets;
  an unavailable target stays unavailable.
- Use microphone holds across devices. Mute cancels active holds, the last valid
  release returns to Muted, and page/disconnect safeguards reject stale holds.
- Choose dual-arc volume/activity gauges, a single-arc activity meter with volume
  percentage, or Classic bars. Assigned dial actions stay available.
- Edit through simpler Action and Appearance sections with visible scroll cues.
  Supported emoji captions have a bundled monochrome fallback.
- Keep both devices working through lock/unlock, USB recovery, suspend, normal
  quit/relaunch and login startup. Discovery and coordinator work is reduced.

## Installation and support

The supported baseline is Fedora Workstation 44 x86_64, GNOME/Wayland. Physical
qualification covers one Plus and one standard MK.2. Use the
[V1.5 installation and update guide](v1.5-verified-installation.md), including its
optional USB access setup for the MK.2. The runtime bundle does not need Rust or
Elgato's Windows software. Administrator USB rules remain a separate step.

Debian 13, Ubuntu 26.04 and Pop!_OS 24.04 COSMIC retain their existing experimental
previews; they are not new supported V1.5 packages. Homebridge remains experimental
with a separately managed companion. General plugins and system monitors target V2.

## Limits and recovery

Navigation and app/page rules remain independent. Linked navigation, general
double-press/hold assignments, Dial Stacks, Action Wheel, Now Playing, wallpaper
and sticky keys are follow-up work.

Keep the previous build and a complete configuration/device-store backup. The
store now uses manifest version 2: a downgrade needs the matching complete
pre-upgrade backup. Binary-only rollback or merging a few files is insufficient.
Enlarged text may require a wider window; full-color/compound emoji shaping is
outside the caption fallback.

The signed candidate averaged 2.7% combined CPU in a five-minute quiet sample and
3.5% in a ten-minute playback/interaction sample, relative to one logical core.
These are finite observations, not universal performance guarantees or matched
V1 comparisons. Numeric visible-response timing remains deferred. Some lifecycle,
accessibility and microphone acceptance is explicitly carried forward from earlier
development builds with unchanged runtime source; see the
[final review and evidence limits](v1.5-release-review.md).

Decksmith is developed with ChatGPT/Codex assistance alongside human design,
review and physical testing. Core controls do not require a cloud account.
