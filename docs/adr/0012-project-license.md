# ADR-0012: Adopt Apache-2.0

Status: Accepted
Date: 2026-09-10

The project owner explicitly approved Apache-2.0 for Decksmith.
Original project code is licensed under Apache-2.0. The full license is in
LICENSE and every current Rust package inherits the workspace SPDX identifier.
Third-party dependencies retain their own licenses.

The archived v0.4 ZIP and imported baseline documents are retained unchanged as
historical source material; their pending-license language is superseded by
this decision. Private Gitea incubation remains the repository strategy.
