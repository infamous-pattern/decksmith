# September 14 — appearance presets, icons and icon sizing

Implemented Maker’s Mark, Dark, Light and High Contrast device-content presets,
shared typography/color/label defaults, key and dial overrides, Reset to theme,
and standalone theme import/export. Legacy custom styles remain explicit overrides.
Themes preserve actions, targets, captions and selected artwork. The existing
shared/page-specific dial behavior and explicit Save and Apply workflow remain.

The offline icon library includes 134 official Tabler outline icons pinned to
v3.46.0, searchable in six categories, plus content-addressed local image imports.
The official full-collection download link is external; no full-set installation
is performed automatically. MIT source notices/checksums are retained, selected
Tabler artwork carries its notice in layout packages, and all three bundled
Liberation Bold fonts retain the OFL license.

User feedback accepted the library and refined sizing to a compact percentage
field with minus/plus buttons, not a slider. The final design starts at 100%,
steps by five percentage points, and accepts 10–100%. It replaces the earlier
fixed-reduction and ten-point suggestions. 100% fits a padded artwork area while
preserving proportions and rendered-label space. Theme defaults can override the
inherited size; Reset to theme restores inheritance. Empty, out-of-range and
non-five-point values keep the previous valid preview and prevent saving until
corrected. Source images are preserved, and size travels through layout history,
persistence and package export/import.

Key and touch-strip previews share the physical Rust renderer. The approved
554-pixel casing / 508-pixel inner device allocation is retained. Label geometry
is used to reserve artwork room; large or wrapped labels can leave a small icon
area, and a middle label places the scaled artwork above it. Existing unthemed
non-library artwork keeps its legacy rendering until scaling or a theme is chosen.
