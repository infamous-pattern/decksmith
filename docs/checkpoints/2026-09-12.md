with a native editor, background device owner, configurable pages/keys/dials,

## Known boundaries

- System output still aliases the default physical output; no independent master
  mixer is present.
- App controls group matching playback streams. Browser tabs/web apps are not
  independently targeted by the current volume selector.
- Installed-app recognition rules are candidates until an actual stream matches.
  Every listed app has not been exercised live.
- Default-device selection does not explicitly move streams pinned elsewhere.
- Touch has no reliable release event for hold-to-talk; taps are mute toggles.
- Push-to-talk cleanup depends on a responsive audio service. Configuration alone
  does not change initial microphone mute state.
- Explicit media choices represent apps/services, not specific browser tabs.
- The full v0.4 storage, plugin, context, packaging, and indicator architecture
  remains broader than the current implementation.
