## Low-signal renderer crash repair

A live-session failure exposed a floating-point bounds error in the glossy bar
geometry. At 4% activity, two mathematically equal clamp limits rounded to 17.44
and 17.439999, panicking the device worker and leaving the physical display frozen.
The journal showed the same failure before the per-page override rollout; the
previous selected-level tests had not exercised the failing low value.

Replaced endpoint clamping with centered nonnegative distances. A new exhaustive
0–100 regression test reproduced the exact panic before the fix and passes for
signal, ordinary and muted bars after it. Full workspace tests and Clippy passed
(44 daemon tests, one ignored). Saved layout checksum was preserved during recovery;
no editor was killed, assignments reset, or audio level/routing changed. The fixed
service resumed changing successfully sent physical frames, and the native editor
accepted draft edits. Live requests measured 34 ms median / 37 ms maximum across
40 checks, with display-ready state retained throughout.


## Meter connection and continuity recovery

Wave peak connections could remain in CREATING with the previous suspend flag.
Comparative stream-option checks also exposed inconsistent app delivery. Minimal
peak-only connections delivered 599 measurements per target over 30 seconds for
Wave, output and Brave, with a 61 ms maximum gap. The production helper additionally
observed an occasional >500 ms Brave packet gap while the same source remained
READY. Removed optional stream flags, validate the actual source before accepting
peaks, and retry stuck connection setup after three seconds. Selected monitored
sources may stay awake; hardware latency settings are not requested or changed.

Brave now gets a bounded decaying display envelope during short packet gaps, with
one-second expiry; failures/moves/removals clear measurements immediately instead
of carrying another source's level. Tests distinguish silence, packet gaps, stale
measurements, failed/moved sources and retry deadlines.

The earlier uninstrumented editor soak timed out without identifying its phase.
Added a ten-second readiness deadline and ten-second progress checkpoints. The
instrumented run completed 91 native checks over 90 seconds, with 91 distinct
frames and repeated unsaved label edits, preserving the saved layout. The original
timeout's exact cause is unproven; the instrumented run did not reproduce a hang.


Deployed the helper with daemon invocation `4a36c9fd2a2e4e11a6356e42fdd6ac7d`.
Pre-deployment production-helper sampling ran 95 seconds (938 outputs per target)
with zero missing values after startup for Wave, output and Brave. Layout checksum

An initial simultaneous noncanonical-preview stress check remained connected for

Replaced polling of the record buffer with the libpulse data-arrival callback.
The callback drains peaks on arrival and coalesces the strongest pending value;

consumption, failure and suspension. The callback comparison ran 95 seconds / 938
outputs per target with zero missing values after startup. The one-second hard
expiry remains unchanged; it was not widened again to hide the residual gaps.
