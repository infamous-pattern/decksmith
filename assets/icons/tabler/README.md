# Tabler starter set

134 unmodified official outline SVGs from Tabler Icons v3.46.0, selected for
Decksmith's technology/application controls. Six searchable categories are listed
in catalog.json. This is a subset of the upstream collection.

Source: https://github.com/tabler/tabler-icons/releases/tag/v3.46.0
Archive: https://codeload.github.com/tabler/tabler-icons/tar.gz/refs/tags/v3.46.0
Full collection downloads: https://github.com/tabler/tabler-icons/releases/latest
